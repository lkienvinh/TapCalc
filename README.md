# 🧮 TapCalc

A simple, clean PyQt6 calculator app with modern UI and theme support.

---

## ✨ Features

- Basic arithmetic operations (+, -, ×, ÷)
- Clean UI made with Qt Designer
- Real-time input validation
- Prevents invalid expressions
- Auto-clear after calculation
- Delete (C) and All Clear (AC)
- Rounding support for decimals
- Lightweight and fast

## 🪟 Windows Installation Guide

### 1. Install Python
Download Python from:

https://www.python.org/downloads/

⚠️ IMPORTANT:
During installation, check:

Add Python to PATH

---

### 2. Download TapCalc
- Click the green **Code** button
- Select **Download ZIP**
- Extract the folder

---

### 3. Open Terminal
Open the TapCalc folder, click the address bar and type:

cmd


Press Enter.

---

### 4. Install Requirements


pip install pyqt6


---

### 5. Run TapCalc


python main.py


---

## 🖥️ Optional: Build EXE

To create a standalone app:


pip install pyinstaller
pyinstaller --onefile --windowed main.py


Your EXE will appear in:


dist/main.exe


---

## 🐧 Linux (Arch) Installation

If using Arch Linux:


makepkg -si


Then run:


tapcalc
